
A harness is the code wrapped around a language model that turns it into an agent - handling tools, memory, loops and parsing outputs.
Its what guide the model to perform or to think in a specific way, what tools to use, what flows to go, how to resond etc..

## PI.DEV
https://pi.dev/
Pi is a minimal agent harness.

## OpenSrc
https://github.com/vercel-labs/opensrc
Add the code base with 
```
npx opensrc <url>
```
## Advantages of Harness
Before when we were referencing a code base, the AI models itself would get all the code  vectorize and transform it and it would blow up the context window. But now the models have got so smart they can just go and just search the code base for the exact function you need. Then it would just feed that into the context window Together with your prompt and perform an exact change that you're looking for.
