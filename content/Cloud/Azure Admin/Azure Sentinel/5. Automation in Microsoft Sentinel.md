## Intro
- Microsoft Sentinel is both Security Information and Event Management (SIEM) and Orchestration, Automation, and Response (SOAR)
- It is at the center of Sec Operation Center - SOC 

## Automation Rules and Playbooks
![[Pasted image 20260711212822.png]]
Automation in Microsoft Sentinel includes automation rules for centrally managing incident handling and response, and playbooks that run predefined action sequences for advanced, flexible threat response.
### Automation rules
- Automation rules centralize incident handling and response.
- Assign an incident to personnel,tag, update status and close them
- Apply responses to multiple analytics rules at once.
- Automatically tag, assign, or close incidents without playbooks.
- Control the execution order of actions.
- Simplify complex workflows and streamline incident orchestration.

### Playbooks
- Playbooks in Microsoft Sentinel are based on workflows built in Azure Logic Apps
- A playbook is a collection of response and remediation actions and logic.
- Automates and orchestrates threat response.
- Integrates with internal and external systems.
- Can run automatically when triggered by an analytics rule or automation rule.
- Can also be run manually on-demand from the incidents page.
>[NOTE]
>Logic Apps are a cloud service that helps you schedule, automate, and orchestrate tasks and workflows across systems throughout the enterprise.

## Create automation rules
Think about incident orchestration, managing incident status, automating playbooks to be run, tagging incidents, assigning them, respond to `Analytic Rules` . Enabling simplified complex 
workflow for incident orchestration (SOAR)

>[NOTE]
>Navigation paths differ by portal. In the **Azure portal**, go to your Microsoft Sentinel workspace and select **Automation** under **Configuration**. In the **Defender portal**, select **Microsoft Sentinel** from the left navigation, then select **Automation**.

- When you need an automation rule that applies to many analytics rules, create it directly in the **Automation** page
