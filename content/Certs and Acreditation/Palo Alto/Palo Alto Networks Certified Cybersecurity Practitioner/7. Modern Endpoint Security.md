## Extended Detection and Response
![[Pasted image 20260910192518.png]]
Extended detection and response (XDR), an evolution of EDR, is a new approach to threat detection and response. The “X” stands for any data source, such as network, cloud, and endpoint sensors.

Traditional EDR tools only monitor endpoint data, which limits threat visibility and can lead to missed detections, more false positives, and slower investigations—worsening challenges like event overload, skills shortages, and fragmented tools. XDR systems address this by using heuristics, analytics, modeling, and automation to combine and analyze data from multiple sources, improving visibility and productivity. This enables simpler, faster threat discovery, hunting, investigation, and response across security operations.

### Why Use XDR?
Because cyberattacks vary and traditional antivirus systems are weak, modern attacks now target both systems and end users. Antivirus can also be bypassed—especially through PowerShell exploits. EDR and XDR help answer many questions about cyberattack-related activity observed on a system.

## Endpoint Protection Platform
“Endpoint security” is often used interchangeably with “endpoint protection platform,” or EPP, a term coined by Gartner. This platform sits on endpoint devices and secures them against cyberattacks using a comprehensive approach to combat sophisticated malware.

| Tool | Summary |
|------|---------|
| **EPP** | Uses multiple prevention techniques, including static analysis (file inspection to evaluate potential malware), heuristic rules (to block exploits), and behavioral analysis (to judge file maliciousness based on the functions it performs). |
| **EDR** | Complements EPP by letting security teams investigate and mitigate threats that prevention tools missed. Endpoint security toolkits may also include endpoint management (asset, vulnerability, patch, and mobile device management), encryption, data loss prevention, and identity and access management—usable alone or bundled with EPP products for broader protection. |

## Endpoint Security Strategies
![[Pasted image 20260910200035.png]]
The following are the endpoint security strategies:
### Modern Endpoint Security

Modern endpoint security solutions focus more on behaviors than signature. They incorporate a broader array of capabilities, such as antivirus, exploit protection, EDR, analytics, and device control.

### Enterprise Endpoint Security

Enterprise endpoint security strategies combine EPP and EDR solutions with cloud and network security tools, such as network traffic analysis (NTA), to gain visibility into the growing proportion of network-connected devices that are “unmanaged” (meaning they do not or cannot have endpoint agents installed), such as many IoT devices.

### Comprehensive Endpoint Security

The most powerful and comprehensive endpoint security solutions (often included in the XDR category) can gather and correlate this data centrally and perform local analysis on individual endpoints.

### Advanced Endpoint Security

An advanced endpoint security solution should prevent known and unknown malware and exploits, incorporate automation to alleviate security team workloads and protect and enable users without impacting system performance.

## User and Entity Behavior Analytics
![[Pasted image 20260910200517.png]]
User and entity behavior analytics (UEBA), or user behavior analytics (UBA), is a type of cybersecurity solution or feature that discovers threats by identifying activity that deviates from a normal baseline.
### Log-Centric Solutions
After establishing this baseline, UEBA solutions apply analytics methods (e.g., simple statistics, pattern matching, rules that leverage signatures) to look for anomalies in traffic patterns that indicate potentially suspicious or malicious activity. For UEBA solutions to perform behavior analytics effectively, a company must first have a robust baseline so any deviation can be marked as suspicious.

### Network-Centric Solutions
NTA(network traffic analysis) solutions use machine learning, advanced analytics, and rule-based detection to monitor and analyze all traffic and flow records on enterprise networks. NTA solutions use this information to identify potential attacks, insider abuse, suspicious activity, and malware. These solutions monitor and analyze all north-south traffic across the enterprise perimeter and all east-west communications from network sensors.
