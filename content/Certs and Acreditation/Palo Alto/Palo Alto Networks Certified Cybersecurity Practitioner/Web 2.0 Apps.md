
### Web 2.0 and Web 2.0 Applications
Apps that are available as (SaaS), web-based, mobile apps or that can run without installing, is known as Web 2.0. The use of these apps is known as Enterprise 2.0

- File Sync Sharing - iCloud,Box,Dropbx,Google Drive, OneDrive,Spotify,Youtube
- IM - Facebook Messenger,Skype,Snapchat,WhatsApps
- Microblogging - Tumble, Twitter
- Office Suits - Ms 365 or Google apps
- Remote Access - LogMeIn, TeamViewer
- Remote Team Meeting - Ms Teams, Zoom, Slack
- Social Curation - Pinterest, Reddit,
- Social Network - Instagram, Facebook, LinkedIN
- Web-Based E-mail - Outlook, Gamil, Yahoo
- Wikis - SocialText,Wikipedia

### Web 3.0
The vision is to return power from the internet to the user, in much the same way Web 1.0 was envisioned to be used. Web 2.0 has become controlled by governments and big corporations. Web 3.0 is a step beyond that.

- AI & Machine Learning 
- Blockchain
- Data Mining - Enables patter to be discovered by large datased using Machine learning
- Mixed Reality - VR(Virtual Reality), AR(Augumented Reality), and XR(Extended Reality)
- Natural Language Search - Ability to understand human language and context rather than boolean search
