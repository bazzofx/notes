## Ten Requirements for Endpoint Security
Although antivirus solutions protect nearly every endpoint and server in the world, security breaches continue at an alarming rate. This is largely because traditional antivirus systems are signature-based security tools that focus on detecting and responding to known threats after they have already entered a network. Experienced attackers can bypass antivirus systems with inexpensive, automated online tools that produce countless unique, unknown attacks. Ultimately, traditional antivirus systems are inadequate for protecting systems against security breaches.

| Requirement | Summary |
|-------------|---------|
| **Pre-Emptively Block Known and Unknown Threats** | Shift from detecting/responding after incidents to preventing breaches upfront. Protect endpoints from known, unknown, and zero-day threats (malware and exploits) regardless of online/offline, on/off-premises, or network connection status. Use local and cloud-based threat analysis to detect and block evasive threats. |
| **Does Not Impact User Productivity** | Let users work with mobile and cloud technologies without fear of unknown threats. Users shouldn't worry about patches/updates and must be confident they're protected from accidentally running malware or exploits. |
| **Automatically Turn Threat Intelligence Into Prevention** | Use threat intelligence from third-party providers and public sharing organizations to instantly prevent known malware, block unknown malware, and stop endpoint infections. Gather internal threat data (network, cloud, endpoint), correlate it via automation, identify indicators of compromise, create protections, and push them organization-wide. |
| **Protect All Applications** | Applications are core to operations, but bugs create attack surfaces traditional antivirus misses. Security infrastructure should fully protect all applications (third-party and proprietary) against exploits and quickly return security verdicts to expedite approval of new apps. |
| **Ensure Security Does Not Impact System Performance** | Security products must not burden RAM, CPU, or disk storage. Protection must never degrade the user experience or require significant system resources. |
| **Keep Legacy Systems Secure** | Organizations may delay updates/patches due to operational risks or because patches don't exist for end-of-life systems. A complete solution must support unpatchable systems by preventing exploitation of known or unknown vulnerabilities regardless of patch availability. |
| **Be Enterprise-Ready** | A replacement antivirus must be scalable, flexible, and manageable for enterprise deployment. It should integrate with enterprise resource deployment, scale to any number of endpoints, support geographically dispersed environments, offer ample protection without overly restricting business needs, and be easily managed without adding operational burden. |
| **Provide Independent Verification for Industry Compliance Requirements** | Compliance often requires antivirus implementation. Vendors replacing antivirus should provide an audit report from an independent third-party compliance/audit organization to help customers achieve and maintain compliance. |
| **Provide Independent Verification as an Antivirus Replacement** | Any product replacing legacy antivirus should have its performance reviewed and validated by an independent third-party security testing/evaluation organization—an essential check beyond internal capabilities. |
| **Receive Recognition of Efficacy From Top-Tier Researchers** | Replacement solutions should be recognized as key players in endpoint security by respected analysts/research firms (e.g., Gartner), ensuring the solution and vendor meet standard viability requirements. |
